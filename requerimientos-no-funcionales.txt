Requerimientos no funcionales
1. RNF-01 — Tiempo de Procesamiento Edge
   El procesamiento debe realizarse en un máximo aproximado de 2,0 segundos por folio a 300 DPI.
2. RNF-02 — Utilización de Recursos (Memoria Edge)
   El consumo sostenido del cliente Edge no debe superar aproximadamente 1,5 GB de RAM en lotes de 1000 folios.
3. RNF-03 — Latencia del Dashboard SaaS
   Las consultas complejas de auditoría del Dashboard deben responder en menos de 800 ms para el percentil 95 (P95).
4. RNF-04 — Confidencialidad en Reposo (Edge Perimetral)
   Los folios, documentos y bitácoras temporales deben estar protegidos mediante AES-256, evitando que puedan ser leídos directamente desde el sistema operativo.
5. RNF-05 — Integridad y Confidencialidad en Tránsito
   Las comunicaciones con la nube y con el SaaS deben utilizar TLS 1.3, rechazando negociaciones criptográficas inferiores.
6. RNF-06 — No Repudio y Responsabilidad (Accountability)
   Los logs deben almacenarse mediante arquitectura append-only, manteniendo una retención mínima de 7 años.
7. RNF-07 — Tolerancia a Fallos y Recuperabilidad (Hardware)
   Después de un atasco o desconexión física del escáner, la captura debe poder reanudarse en un máximo de 5 segundos, conservando el estado de la sesión.
8. RNF-08 — Disponibilidad del Entorno de Gobernanza
   El panel SaaS debe mantener una disponibilidad de aproximadamente 99,9 % anual.
9. RNF-09 — Interoperabilidad de Captura de Hardware
   La aplicación debe poder adquirir imágenes utilizando los estándares TWAIN v2.0+ y WIA, dependiendo de los controladores OEM correspondientes.
10. RNF-10 — Interoperabilidad de Destino en la Nube
    El sistema debe integrarse mediante APIs RESTful con Google Drive API v3 y Dropbox API v2, utilizando OAuth 2.0 para la autorización.
11. RNF-11 — Adaptabilidad del Entorno Operativo (Edge)
    El cliente Desktop debe ejecutarse nativamente en sistemas Microsoft Windows 10 y Windows 11 de 64 bits.
12. RNF-12 — Adaptabilidad del Entorno Web (SaaS)
    El panel SaaS debe funcionar sin degradación en las tres últimas versiones estables de Chrome, Microsoft Edge y Firefox.
13. RNF-13 — Modificabilidad y Despliegue No Invasivo
    El motor de IA debe estar desacoplado de la interfaz, permitiendo actualizaciones del modelo mediante un mecanismo tipo OTA sin tener que reinstalar completamente el cliente de escritorio.
14. RNF-14 — No Exposición de Secretos en Cliente
    Las contraseñas utilizadas para proteger documentos no deben enviarse al navegador. La visualización debe resolverse en el servidor, enviando únicamente representaciones visuales y evitando caché persistente.
15. RNF-15 — Protección del Login Web
    El login web debe validar CAPTCHA del lado del servidor y exigir Authenticator/TOTP cuando la cuenta lo tenga activado o una política global lo requiera.
16. RNF-16 — Confidencialidad de Secretos Authenticator
    El secreto empleado para Authenticator no puede aparecer en listados generales de usuarios; solo debe mostrarse durante un proceso controlado de configuración administrativa.
